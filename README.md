## ⚡ Sobre Mí

Ingeniero enfocado en **sistemas Linux, infraestructura local, automatización y herramientas de backend en Python**. Me apasiona el diseño de software defensivo, la observabilidad a nivel de kernel (`/proc`, `/sys`) y la creación de plataformas de desarrollo internas (IDP) que reemplazan el desorden por interfaces fluidas, deterministas y de alto rendimiento.

* 🐧 **Ecosistema:** Entornos Linux nativos, administración de kernels modernos, scripting Bash avanzado y gestión de instantáneas atómicas con **Btrfs/Snapper**.
* 🛠️ **Arquitectura de Software:** Desarrollo modular en Python con **PySide6 / Qt6**, desacoplamiento de capas, control de concurrencia y telemetría de ultra-baja latencia (<1ms).
* 🔒 **Soberanía & Privacidad:** Integración de modelos de lenguaje locales (Ollama) sin fugas de telemetría saliente ni dependencia ciega de APIs de terceros.
* 📦 **Operaciones & DevOps:** GitOps riguroso, contenedores Docker, auditoría de puertos de red y pruebas automatizadas continuas.

## 🏛️ Proyecto Insignia

### ❖ [ABRAXAS — Developer Platform & Linux System Orchestrator](https://github.com/Silvynth/ABRAXAS)
> *Internal Developer Platform (IDP) y estación de mando táctica para Linux a 60 FPS.*

* **Telemetría de Kernel:** Monitoreo atómico directo sobre `/proc` (CPU, RAM, GPU, NVMe I/O y Red) con consumo de CPU < 0.5%.
* **Resiliencia Operativa:** Instantáneas Btrfs automáticas previas a actualizaciones del sistema con capacidad de rollback inmediato.
* **Ciclo de Vida GitOps:** Grafo interactivo de ramas, simulación táctica de fusiones (*dry-run*) y commits convencionales guiados.
* **IA Soberana:** Motor NOUS desacoplado sobre servidor local de Ollama para análisis seguro de código sin salida a la nube.
